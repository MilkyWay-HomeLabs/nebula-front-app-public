# Contributing to the Project

Thank you for your interest in contributing to the project! If you want to report a bug, suggest a new feature, or submit a pull request, please follow the guidelines below:

## Reporting Bugs
- Provide a detailed description of the problem and the steps to reproduce it.
- Include logs, screenshots, or any other helpful information.

## Feature Requests
- Describe the motivation and potential benefits of the proposed change.
- If possible, suggest an example implementation.

## Pull Requests
- Ensure the code passes all tests (`npm run test` and `npm run test:e2e`).
- Adhere to the project's coding style and standards.
- Update the changelog with your changes.

## Contact
- If you have any questions, feel free to contact the project maintainers.
